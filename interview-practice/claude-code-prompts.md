# Claude Code 提示词工程专题面试题

来源：[图解 Claude Code](https://xiaolinnote.com/claudecode/)的提示词工程专题，共 2 篇文章。每篇一个题组，每个编号只考一个主要问题；本卷使用 `I` 前缀。

原文以特定名称的系统提示词解读为背景。本卷提炼工具设计、状态管理和交互方法，不复刻提示词全文，也不将作者所称的泄漏内容、工具数量或模型名称视为已核实的官方规格。
