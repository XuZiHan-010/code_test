- **W1-2** 权限相关的常用命令是 chmod、chown、useradd、groupadd。ps、top、kill、pkill 属于进程相关，mv、mkdir、cd、ls 属于文件相关，netstat、ip addr 属于网络相关，ping、telnet 属于测试相关。[原文§Linux的常用命令了解过哪些？](https://xiaolincoding.com/interview/linux.html#linux%E7%9A%84%E5%B8%B8%E7%94%A8%E5%91%BD%E4%BB%A4%E4%BA%86%E8%A7%A3%E8%BF%87%E5%93%AA%E4%BA%9B)
- **W1-3** 三个空是进程相关、权限相关、网络相关（顺序不限）。文件相关有 mv、mkdir、cd、ls，测试相关有 ping、telnet。[原文§Linux的常用命令了解过哪些？](https://xiaolincoding.com/interview/linux.html#linux%E7%9A%84%E5%B8%B8%E7%94%A8%E5%91%BD%E4%BB%A4%E4%BA%86%E8%A7%A3%E8%BF%87%E5%93%AA%E4%BA%9B)
- **W1-4** 文件相关的常用命令是 mv、mkdir、cd、ls。kill 属于进程相关，chmod 属于权限相关。[原文§Linux的常用命令了解过哪些？](https://xiaolincoding.com/interview/linux.html#linux%E7%9A%84%E5%B8%B8%E7%94%A8%E5%91%BD%E4%BB%A4%E4%BA%86%E8%A7%A3%E8%BF%87%E5%93%AA%E4%BA%9B)

- **W1-6** 原文：telnet 用来测试端口连通性，ping 用来测试网络连通性；netstat、ip addr 是网络相关的命令。[原文§Linux的常用命令了解过哪些？](https://xiaolincoding.com/interview/linux.html#linux%E7%9A%84%E5%B8%B8%E7%94%A8%E5%91%BD%E4%BB%A4%E4%BA%86%E8%A7%A3%E8%BF%87%E5%93%AA%E4%BA%9B)
- **W1-7** 原文把 netstat、ip addr 归为网络相关的命令。文件相关是 mv、mkdir、cd、ls，进程相关是 ps、top、kill、pkill，权限相关是 chmod、chown、useradd、groupadd。[原文§Linux的常用命令了解过哪些？](https://xiaolincoding.com/interview/linux.html#linux%E7%9A%84%E5%B8%B8%E7%94%A8%E5%91%BD%E4%BB%A4%E4%BA%86%E8%A7%A3%E8%BF%87%E5%93%AA%E4%BA%9B)
- **W1-8** 原文按用途把常用命令分成五类：文件相关有 mv、mkdir、cd、ls；进程相关有 ps、top、kill、pkill；权限相关有 chmod、chown、useradd、groupadd；网络相关有 netstat、ip addr；测试相关有 ping（测试网络连通性）和 telnet（测试端口连通性）。[原文§Linux的常用命令了解过哪些？](https://xiaolincoding.com/interview/linux.html#linux%E7%9A%84%E5%B8%B8%E7%94%A8%E5%91%BD%E4%BB%A4%E4%BA%86%E8%A7%A3%E8%BF%87%E5%93%AA%E4%BA%9B)

### ps命令里都有哪些选项，ps展示哪些东西？

- **W1-9** ps 展示 PID（进程 ID）、PPID（父进程 ID）、STAT（进程状态）、TTY（终端设备）等。Load average 是 top 展示的内容，buff/cache 是 free 展示的内容，都不是 ps 的展示项。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-10** RSS 是物理内存大小。虚拟内存大小是 VSZ，进程累计 CPU 占用时间是 TIME，进程启动时间是 START。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-11** VSZ 是虚拟内存大小。物理内存大小是 RSS，进程状态是 STAT，终端设备是 TTY。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-12** STAT 是进程状态。终端设备是 TTY，进程所属用户是 USER，进程命令或可执行文件是 COMMAND。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-13** TIME 是进程累计 CPU 占用时间。进程启动时间是 START，物理内存大小是 RSS，进程所属用户是 USER。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-14** TTY 是终端设备。进程状态是 STAT，进程启动时间是 START，父进程 ID 是 PPID。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-15** -e 显示系统中所有进程，等同于 -A。原文特别说明 -a 并不等同于 -e；-f 显示详细信息，-o 自定义输出格式。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-16** -a 显示与终端关联的所有进程（包括其他用户的进程，但不含会话首进程），原文强调它并不等同于 -e；-e 才是显示系统中所有进程。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-17** -o 用于自定义输出格式。显示系统中所有进程的是 -e，显示详细进程信息的是 -f，显示与终端关联的所有进程的是 -a。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-18** -f 显示详细的进程信息。自定义输出格式的是 -o，显示系统中所有进程的是 -e，显示没有控制终端的进程的是 -x。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-19** 正确的是：-e 等同于 -A 并显示所有进程；-a 不等同于 -e；-o 自定义输出格式；-f 显示详细的进程信息。说 -a 等同于 -e 违背原文的特别说明，详细信息对应的是 -f 而不是 -o。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)
- **W1-20** ps 展示的内容有：PID（进程 ID）、PPID（父进程 ID）、USER（进程所属用户）、%CPU（CPU 占用率）、%MEM（内存占用率）、VSZ（虚拟内存大小）、RSS（物理内存大小）、TTY（终端设备）、STAT（进程状态）、START（进程启动时间）、TIME（进程累计 CPU 占用时间）、COMMAND（进程命令或可执行文件）。常用选项：-e 显示系统中所有进程，等同于 -A；-a 显示与终端关联的所有进程（包括其他用户的，但不含会话首进程），并不等同于 -e；-f 显示详细的进程信息；-o 自定义输出格式。[原文§ps命令里都有哪些选项，ps展示哪些东西？](https://xiaolincoding.com/interview/linux.html#ps%E5%91%BD%E4%BB%A4%E9%87%8C%E9%83%BD%E6%9C%89%E5%93%AA%E4%BA%9B%E9%80%89%E9%A1%B9-ps%E5%B1%95%E7%A4%BA%E5%93%AA%E4%BA%9B%E4%B8%9C%E8%A5%BF)

### top命令会展示什么东西，里面每一项都是呈现什么样的数据？

- **W1-21** 两个空是 CPU 使用情况、交换空间使用情况（顺序不限）。[原文§top命令会展示什么东西，里面每一项都是呈现什么样的数据？](https://xiaolincoding.com/interview/linux.html#top%E5%91%BD%E4%BB%A4%E4%BC%9A%E5%B1%95%E7%A4%BA%E4%BB%80%E4%B9%88%E4%B8%9C%E8%A5%BF-%E9%87%8C%E9%9D%A2%E6%AF%8F%E4%B8%80%E9%A1%B9%E9%83%BD%E6%98%AF%E5%91%88%E7%8E%B0%E4%BB%80%E4%B9%88%E6%A0%B7%E7%9A%84%E6%95%B0%E6%8D%AE)
- **W1-22** Load average 显示最近 1 分钟、5 分钟和 15 分钟的平均负载。进程各状态的数量是 Tasks，物理内存是 Memory usage，交换空间是 Swap usage。[原文§top命令会展示什么东西，里面每一项都是呈现什么样的数据？](https://xiaolincoding.com/interview/linux.html#top%E5%91%BD%E4%BB%A4%E4%BC%9A%E5%B1%95%E7%A4%BA%E4%BB%80%E4%B9%88%E4%B8%9C%E8%A5%BF-%E9%87%8C%E9%9D%A2%E6%AF%8F%E4%B8%80%E9%A1%B9%E9%83%BD%E6%98%AF%E5%91%88%E7%8E%B0%E4%BB%80%E4%B9%88%E6%A0%B7%E7%9A%84%E6%95%B0%E6%8D%AE)
- **W1-23** 三个空是睡眠、停止、僵尸（顺序不限）。[原文§top命令会展示什么东西，里面每一项都是呈现什么样的数据？](https://xiaolincoding.com/interview/linux.html#top%E5%91%BD%E4%BB%A4%E4%BC%9A%E5%B1%95%E7%A4%BA%E4%BB%80%E4%B9%88%E4%B8%9C%E8%A5%BF-%E9%87%8C%E9%9D%A2%E6%AF%8F%E4%B8%80%E9%A1%B9%E9%83%BD%E6%98%AF%E5%91%88%E7%8E%B0%E4%BB%80%E4%B9%88%E6%A0%B7%E7%9A%84%E6%95%B0%E6%8D%AE)
- **W1-24** 内存使用情况包括物理内存的总量、已使用量、空闲量，以及缓冲区和缓存区的使用量。平均负载属于 Load average 部分。[原文§top命令会展示什么东西，里面每一项都是呈现什么样的数据？](https://xiaolincoding.com/interview/linux.html#top%E5%91%BD%E4%BB%A4%E4%BC%9A%E5%B1%95%E7%A4%BA%E4%BB%80%E4%B9%88%E4%B8%9C%E8%A5%BF-%E9%87%8C%E9%9D%A2%E6%AF%8F%E4%B8%80%E9%A1%B9%E9%83%BD%E6%98%AF%E5%91%88%E7%8E%B0%E4%BB%80%E4%B9%88%E6%A0%B7%E7%9A%84%E6%95%B0%E6%8D%AE)
- **W1-25** CPU usage 显示 CPU 的总体使用率以及每个 CPU 核心的使用率。进程数量是 Tasks，平均负载是 Load average，交换空间是 Swap usage。[原文§top命令会展示什么东西，里面每一项都是呈现什么样的数据？](https://xiaolincoding.com/interview/linux.html#top%E5%91%BD%E4%BB%A4%E4%BC%9A%E5%B1%95%E7%A4%BA%E4%BB%80%E4%B9%88%E4%B8%9C%E8%A5%BF-%E9%87%8C%E9%9D%A2%E6%AF%8F%E4%B8%80%E9%A1%B9%E9%83%BD%E6%98%AF%E5%91%88%E7%8E%B0%E4%BB%80%E4%B9%88%E6%A0%B7%E7%9A%84%E6%95%B0%E6%8D%AE)
- **W1-26** Swap usage 显示交换空间的总量、已使用量和剩余量。物理内存是 Memory usage，CPU 使用率是 CPU usage，平均负载是 Load average。[原文§top命令会展示什么东西，里面每一项都是呈现什么样的数据？](https://xiaolincoding.com/interview/linux.html#top%E5%91%BD%E4%BB%A4%E4%BC%9A%E5%B1%95%E7%A4%BA%E4%BB%80%E4%B9%88%E4%B8%9C%E8%A5%BF-%E9%87%8C%E9%9D%A2%E6%AF%8F%E4%B8%80%E9%A1%B9%E9%83%BD%E6%98%AF%E5%91%88%E7%8E%B0%E4%BB%80%E4%B9%88%E6%A0%B7%E7%9A%84%E6%95%B0%E6%8D%AE)
- **W1-27** 进程列表显示进程的 PID、用户、CPU 占用率、内存占用率、进程状态和进程命令等。TCP 连接的四元组由 netstat 观察，OOM 记录要查 dmesg，都不在 top 的进程列表里。[原文§top命令会展示什么东西，里面每一项都是呈现什么样的数据？](https://xiaolincoding.com/interview/linux.html#top%E5%91%BD%E4%BB%A4%E4%BC%9A%E5%B1%95%E7%A4%BA%E4%BB%80%E4%B9%88%E4%B8%9C%E8%A5%BF-%E9%87%8C%E9%9D%A2%E6%AF%8F%E4%B8%80%E9%A1%B9%E9%83%BD%E6%98%AF%E5%91%88%E7%8E%B0%E4%BB%80%E4%B9%88%E6%A0%B7%E7%9A%84%E6%95%B0%E6%8D%AE)
- **W1-28** top 主要展示：Load average（最近 1、5、15 分钟的平均负载）；Tasks（运行、睡眠、停止和僵尸状态的进程数量）；CPU usage（CPU 的总体使用率以及每个 CPU 核心的使用率）；Memory usage（物理内存的总量、已使用量、空闲量、缓冲区和缓存区的使用量）；Swap usage（交换空间的总量、已使用量和剩余量）；以及进程列表（进程的 PID、用户、CPU 占用率、内存占用率、进程状态和进程命令等）。[原文§top命令会展示什么东西，里面每一项都是呈现什么样的数据？](https://xiaolincoding.com/interview/linux.html#top%E5%91%BD%E4%BB%A4%E4%BC%9A%E5%B1%95%E7%A4%BA%E4%BB%80%E4%B9%88%E4%B8%9C%E8%A5%BF-%E9%87%8C%E9%9D%A2%E6%AF%8F%E4%B8%80%E9%A1%B9%E9%83%BD%E6%98%AF%E5%91%88%E7%8E%B0%E4%BB%80%E4%B9%88%E6%A0%B7%E7%9A%84%E6%95%B0%E6%8D%AE)

### 已知一个进程名，如何杀掉这个进程？

- **W1-29** 原文把“直接按进程名杀”标为推荐方式：pkill 或 killall，不用手动查 PID。“ps + kill 两步走”只是另一种方式，并不是唯一做法；按端口号杀、先找线程 ID 都不是原文给出的做法。[原文§已知一个进程名，如何杀掉这个进程？](https://xiaolincoding.com/interview/linux.html#%E5%B7%B2%E7%9F%A5%E4%B8%80%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%90%8D-%E5%A6%82%E4%BD%95%E6%9D%80%E6%8E%89%E8%BF%99%E4%B8%AA%E8%BF%9B%E7%A8%8B)
- **W1-30** “ps + kill 两步走”里，第一步 `ps -ef | grep <进程名>` 只是查找进程的 PID；终止进程要靠第二步的 kill。[原文§已知一个进程名，如何杀掉这个进程？](https://xiaolincoding.com/interview/linux.html#%E5%B7%B2%E7%9F%A5%E4%B8%80%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%90%8D-%E5%A6%82%E4%BD%95%E6%9D%80%E6%8E%89%E8%BF%99%E4%B8%AA%E8%BF%9B%E7%A8%8B)
- **W1-31** 依次填：SIGTERM、15。[原文§已知一个进程名，如何杀掉这个进程？](https://xiaolincoding.com/interview/linux.html#%E5%B7%B2%E7%9F%A5%E4%B8%80%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%90%8D-%E5%A6%82%E4%BD%95%E6%9D%80%E6%8E%89%E8%BF%99%E4%B8%AA%E8%BF%9B%E7%A8%8B)
- **W1-32** 依次填：SIGKILL、9。[原文§已知一个进程名，如何杀掉这个进程？](https://xiaolincoding.com/interview/linux.html#%E5%B7%B2%E7%9F%A5%E4%B8%80%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%90%8D-%E5%A6%82%E4%BD%95%E6%9D%80%E6%8E%89%E8%BF%99%E4%B8%AA%E8%BF%9B%E7%A8%8B)
- **W1-33** 原文：一般优先用 SIGTERM，让进程做一些清理工作再退出；kill -9 发送 SIGKILL，直接强制终止，来不及释放资源。其余几项把两者的特点说反了，或原文没有这样说。[原文§已知一个进程名，如何杀掉这个进程？](https://xiaolincoding.com/interview/linux.html#%E5%B7%B2%E7%9F%A5%E4%B8%80%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%90%8D-%E5%A6%82%E4%BD%95%E6%9D%80%E6%8E%89%E8%BF%99%E4%B8%AA%E8%BF%9B%E7%A8%8B)
- **W1-34** 原文：只有在进程不响应或卡死时才使用 kill -9，因为它直接强制终止进程；平时优先用 SIGTERM。[原文§已知一个进程名，如何杀掉这个进程？](https://xiaolincoding.com/interview/linux.html#%E5%B7%B2%E7%9F%A5%E4%B8%80%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%90%8D-%E5%A6%82%E4%BD%95%E6%9D%80%E6%8E%89%E8%BF%99%E4%B8%AA%E8%BF%9B%E7%A8%8B)
- **W1-35** 原文：pkill 按进程名模糊匹配并杀死，killall 按进程名精确匹配并杀死所有同名进程。[原文§已知一个进程名，如何杀掉这个进程？](https://xiaolincoding.com/interview/linux.html#%E5%B7%B2%E7%9F%A5%E4%B8%80%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%90%8D-%E5%A6%82%E4%BD%95%E6%9D%80%E6%8E%89%E8%BF%99%E4%B8%AA%E8%BF%9B%E7%A8%8B)
- **W1-36** 原文把 `pkill -9 <进程名>` 标注为“强制终止”：按进程名发送 SIGKILL。它按进程名而不是 PID 匹配。[原文§已知一个进程名，如何杀掉这个进程？](https://xiaolincoding.com/interview/linux.html#%E5%B7%B2%E7%9F%A5%E4%B8%80%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%90%8D-%E5%A6%82%E4%BD%95%E6%9D%80%E6%8E%89%E8%BF%99%E4%B8%AA%E8%BF%9B%E7%A8%8B)
- **W1-37** 原文给出的方式有：ps 加 kill 两步走、pkill、killall（以及它们的强制版本）。netstat 用来查看网络连接，top -H 用来查看线程状态，都不能终止进程。[原文§已知一个进程名，如何杀掉这个进程？](https://xiaolincoding.com/interview/linux.html#%E5%B7%B2%E7%9F%A5%E4%B8%80%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%90%8D-%E5%A6%82%E4%BD%95%E6%9D%80%E6%8E%89%E8%BF%99%E4%B8%AA%E8%BF%9B%E7%A8%8B)
- **W1-38** 有两种方式。方式一是 ps 加 kill 两步走：先用 `ps -ef | grep <进程名>` 找到 PID，再用 `kill <PID>`（发送 SIGTERM，信号 15，优雅终止）或 `kill -9 <PID>`（发送 SIGKILL，信号 9，强制终止）。方式二（推荐）是直接按进程名杀：`pkill <进程名>` 按进程名模糊匹配并杀死，`pkill -9 <进程名>` 强制终止，`killall <进程名>` 按进程名精确匹配并杀死所有同名进程。一般优先用 SIGTERM，让进程做一些清理工作再退出；只有进程不响应或卡死时才用 kill -9，因为它直接强制终止，来不及释放资源。[原文§已知一个进程名，如何杀掉这个进程？](https://xiaolincoding.com/interview/linux.html#%E5%B7%B2%E7%9F%A5%E4%B8%80%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%90%8D-%E5%A6%82%E4%BD%95%E6%9D%80%E6%8E%89%E8%BF%99%E4%B8%AA%E8%BF%9B%E7%A8%8B)

## 2. 网络与权限

### 如何查看网络连接情况？

- **W2-1** 原文用 netstat（如 `netstat -napt`）查看网络连接情况。free -m 看内存，uptime 看平均负载，mpstat 看 CPU 性能。[原文§如何查看网络连接情况？](https://xiaolincoding.com/interview/linux.html#%E5%A6%82%E4%BD%95%E6%9F%A5%E7%9C%8B%E7%BD%91%E7%BB%9C%E8%BF%9E%E6%8E%A5%E6%83%85%E5%86%B5)
- **W2-2** `netstat -napt` 显示服务器上的 TCP 连接状态。进程的 CPU 占用率看 ps/top，内存看 free，平均负载看 uptime/top。[原文§如何查看网络连接情况？](https://xiaolincoding.com/interview/linux.html#%E5%A6%82%E4%BD%95%E6%9F%A5%E7%9C%8B%E7%BD%91%E7%BB%9C%E8%BF%9E%E6%8E%A5%E6%83%85%E5%86%B5)
- **W2-3** 原文：可以观察到每一个 TCP 连接的状态，以及四元组信息（源 IP 地址、目标 IP 地址、源端口、目标端口）。内存占用率和平均负载不是 netstat 展示的内容。[原文§如何查看网络连接情况？](https://xiaolincoding.com/interview/linux.html#%E5%A6%82%E4%BD%95%E6%9F%A5%E7%9C%8B%E7%BD%91%E7%BB%9C%E8%BF%9E%E6%8E%A5%E6%83%85%E5%86%B5)
- **W2-4** 四个空是源 IP 地址、目标 IP 地址、源端口、目标端口（顺序不限）。[原文§如何查看网络连接情况？](https://xiaolincoding.com/interview/linux.html#%E5%A6%82%E4%BD%95%E6%9F%A5%E7%9C%8B%E7%BD%91%E7%BB%9C%E8%BF%9E%E6%8E%A5%E6%83%85%E5%86%B5)

### 怎么查看哪个端口被哪个进程占用？

- **W2-5** 原文用 lsof 或 netstat 查看端口占用，并推荐用 ss -lntp 精确定位。telnet 用来测试端口能否访问，ping 用来测试网络连通性，都不能说明端口被哪个进程占用。[原文§怎么查看哪个端口被哪个进程占用？](https://xiaolincoding.com/interview/linux.html#%E6%80%8E%E4%B9%88%E6%9F%A5%E7%9C%8B%E5%93%AA%E4%B8%AA%E7%AB%AF%E5%8F%A3%E8%A2%AB%E5%93%AA%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%8D%A0%E7%94%A8)
- **W2-6** 原文注意事项：`grep 80` 会匹配所有含“80”的字符，比如 8080、PID 里含 80 等，过滤不准确。[原文§怎么查看哪个端口被哪个进程占用？](https://xiaolincoding.com/interview/linux.html#%E6%80%8E%E4%B9%88%E6%9F%A5%E7%9C%8B%E5%93%AA%E4%B8%AA%E7%AB%AF%E5%8F%A3%E8%A2%AB%E5%93%AA%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%8D%A0%E7%94%A8)
- **W2-7** 原文推荐用 `grep ':80 '`（冒号 + 空格）精确定位端口字段，或者直接用 `ss -lntp sport = :80`。grep -c、grep -o 是统计次数的写法，不是用来定位端口的。[原文§怎么查看哪个端口被哪个进程占用？](https://xiaolincoding.com/interview/linux.html#%E6%80%8E%E4%B9%88%E6%9F%A5%E7%9C%8B%E5%93%AA%E4%B8%AA%E7%AB%AF%E5%8F%A3%E8%A2%AB%E5%93%AA%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%8D%A0%E7%94%A8)
- **W2-8** 可以通过 lsof 或 netstat 查看，例如查看 80 端口：`lsof -i :80`，输出里有占用该端口的进程名（COMMAND）、PID 和连接状态；或者 `netstat -napt | grep ':80 '`，最后一列能看到 PID 和进程名。注意 `grep 80` 会匹配所有含“80”的字符（比如 8080、PID 里含 80），过滤不准确；推荐用 `grep ':80 '`（冒号加空格）精确定位端口字段，或者直接用 `ss -lntp sport = :80`。[原文§怎么查看哪个端口被哪个进程占用？](https://xiaolincoding.com/interview/linux.html#%E6%80%8E%E4%B9%88%E6%9F%A5%E7%9C%8B%E5%93%AA%E4%B8%AA%E7%AB%AF%E5%8F%A3%E8%A2%AB%E5%93%AA%E4%B8%AA%E8%BF%9B%E7%A8%8B%E5%8D%A0%E7%94%A8)

### 端口通不通用什么命令？

- **W2-9** 原文：telnet 可以测试特定端口的可访问性，示例 `telnet IP地址 端口号`。ping 测试的是网络连通性，netstat 看本机的网络连接，uptime 看平均负载。[原文§端口通不通用什么命令？](https://xiaolincoding.com/interview/linux.html#%E7%AB%AF%E5%8F%A3%E9%80%9A%E4%B8%8D%E9%80%9A%E7%94%A8%E4%BB%80%E4%B9%88%E5%91%BD%E4%BB%A4)
- **W2-10** 填：netcat。[原文§端口通不通用什么命令？](https://xiaolincoding.com/interview/linux.html#%E7%AB%AF%E5%8F%A3%E9%80%9A%E4%B8%8D%E9%80%9A%E7%94%A8%E4%BB%80%E4%B9%88%E5%91%BD%E4%BB%A4)
- **W2-11** 原文：用 telnet 测试时，能够建立连接表示端口通畅，连接失败或超时表示端口不可访问。[原文§端口通不通用什么命令？](https://xiaolincoding.com/interview/linux.html#%E7%AB%AF%E5%8F%A3%E9%80%9A%E4%B8%8D%E9%80%9A%E7%94%A8%E4%BB%80%E4%B9%88%E5%91%BD%E4%BB%A4)
- **W2-12** 原文：telnet 连接失败或超时、nc -zv 连接失败或被拒绝，都表示端口不可访问；能建立连接、能成功连接才表示端口通畅。[原文§端口通不通用什么命令？](https://xiaolincoding.com/interview/linux.html#%E7%AB%AF%E5%8F%A3%E9%80%9A%E4%B8%8D%E9%80%9A%E7%94%A8%E4%BB%80%E4%B9%88%E5%91%BD%E4%BB%A4)

### sed和awk有什么区别？

- **W3-7** 原文：sed 主要用于对文本进行替换、删除、插入等操作，适合对整行文本处理。按列处理、条件判断和循环是 awk 的特点。[原文§sed和awk有什么区别？](https://xiaolincoding.com/interview/linux.html#sed%E5%92%8Cawk%E6%9C%89%E4%BB%80%E4%B9%88%E5%8C%BA%E5%88%AB)
- **W3-8** 原文：awk 可以实现更复杂的文本处理逻辑，适合处理结构化文本数据，可以按列处理。简单的替换、删除、插入和整行处理是 sed 的特点。[原文§sed和awk有什么区别？](https://xiaolincoding.com/interview/linux.html#sed%E5%92%8Cawk%E6%9C%89%E4%BB%80%E4%B9%88%E5%8C%BA%E5%88%AB)
- **W3-9** 原文：awk 可以实现更复杂的文本处理逻辑，包括字段操作、条件判断、循环等，适合按列处理结构化文本。“只适合简单替换”描述的是 sed，说 awk 比 sed 简单违背原文。[原文§sed和awk有什么区别？](https://xiaolincoding.com/interview/linux.html#sed%E5%92%8Cawk%E6%9C%89%E4%BB%80%E4%B9%88%E5%8C%BA%E5%88%AB)
- **W3-10** 原文：sed 适合简单的文本替换和编辑操作，awk 适合处理结构化文本数据并实现更复杂的处理逻辑。[原文§sed和awk有什么区别？](https://xiaolincoding.com/interview/linux.html#sed%E5%92%8Cawk%E6%9C%89%E4%BB%80%E4%B9%88%E5%8C%BA%E5%88%AB)
- **W3-11** 原文：awk 适合处理结构化的文本数据，可以按列对数据进行处理；sed 更适合简单的替换和编辑。[原文§sed和awk有什么区别？](https://xiaolincoding.com/interview/linux.html#sed%E5%92%8Cawk%E6%9C%89%E4%BB%80%E4%B9%88%E5%8C%BA%E5%88%AB)
- **W3-12** 两者都是文本处理工具。sed 主要用于对文本进行替换、删除、插入等操作，适合对整行文本处理，可以通过正则表达式匹配文本再操作，适合简单的文本替换和编辑。awk 可以实现更复杂的文本处理逻辑，包括对字段的操作、条件判断、循环等，适合处理结构化的文本数据，可以按列对数据进行处理。[原文§sed和awk有什么区别？](https://xiaolincoding.com/interview/linux.html#sed%E5%92%8Cawk%E6%9C%89%E4%BB%80%E4%B9%88%E5%8C%BA%E5%88%AB)

- **W4-29** 依次填：所有 CPU、1 秒。[原文§Linux 服务器当中如何查看负载情况？通过什么指标进行查看？](https://xiaolincoding.com/interview/linux.html#linux-%E6%9C%8D%E5%8A%A1%E5%99%A8%E5%BD%93%E4%B8%AD%E5%A6%82%E4%BD%95%E6%9F%A5%E7%9C%8B%E8%B4%9F%E8%BD%BD%E6%83%85%E5%86%B5-%E9%80%9A%E8%BF%87%E4%BB%80%E4%B9%88%E6%8C%87%E6%A0%87%E8%BF%9B%E8%A1%8C%E6%9F%A5%E7%9C%8B)
