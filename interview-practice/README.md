## 出题规则

题库只按小林原文出题（FastAPI 专题的“原文”是 FastAPI 官方中文文档，规则相同），2026-10-13 按下面三条逐篇整理过一遍：

- 每道题都能用所在题组那篇文章的内容回答，答案注明出自哪一小节；
- 原文讲到的知识点都要有题，逐篇对照正文补了漏题，补出的题放在各题组末尾的“补充考点”里；
- 原文没讲的内容不出题，原先问到原文之外的题已改写为只问原文讲到的部分，改不了的删除。
- 原文自身有误或前后矛盾时不照抄：答案写核实后的说法，用括号注明原文是怎么写的，并在引用里加一条以“核对来源：”开头的链接。这是唯一允许使用原文以外来源的情况。

题组之间不做跨卷去重：同一个机制在不同文章里出现时，按各自文章的讲法分别出题。

### 题型与填空规则

按知识点内容选择单选、多选、填空或简答，不按比例凑题型。明确的组成、类别、术语和固定步骤适合填空；原因、机制、取舍、对比与情景推理保留简答。需要辨别正确与错误选项时可用选择题。

2026-10-13 对照现有参考答案，将 15 个专题中的 57 道题调整为填空题，详见[调整清单](fill-audit-2026-10-13.md)。例如 `M1-22` 为 Harness 六层组成的六空题。随后给其余 14 个专题逐章出题时又有 177 道题改成填空，题卷里当时共 234 道填空题，这两次调整都没有改动题号、题序、题数和原文参考答案。2026-10-14 补题时又新增 12 道填空题，同日复核时 D8-12 由单选改为三空填空，共 247 道；同日新增的 Python 专题有 30 道填空题，现在共 277 道；同日新增的数据结构与算法专题有 67 道填空题，共 344 道；同日新增的 MySQL 专题有 120 道填空题，共 464 道；2026-10-15 新增的计算机网络专题有 101 道填空题，共 565 道；同日新增的 FastAPI 专题有 29 道填空题，共 594 道；同日新增的操作系统专题有 63 道填空题，共 657 道；同日新增的 Linux 命令专题有 22 道填空题，共 679 道；同日新增的 Git 专题有 28 道填空题，共 707 道；2026-10-16 新增的 Docker 专题有 28 道填空题，共 735 道；2026-10-19 新增的 Redis 专题有 90 道填空题，合计 825 道（2026-10-25 按用户要求移除 RPA 开发专题及其 5 道填空题）。

- 题卷用 `[填空题·无序]` 或 `[填空题·有序]` 标记，用 `____` 表示一个空。
- 组成、类别等并列列举通常无序；明确步骤、位置或含义对应的题采用有序。网页逐空输入，自动保存。
- 填空由 DeepSeek 根据参考答案按语义评判，接受同义表达、合理缩写和中英文术语；无序题不要求原文排列顺序，有序题按题干位置判断。
- 沿用整题对错计分。每空都填写且覆盖全部所问考点才判对，重复同一项不能抵充缺漏；不要求复述参考答案中题干未问的解释细节。部分填答可以保存和提交，评语指出缺漏；全空按未答处理。
- `content/typed/` 已覆盖 25 个专题、225 章，每题都已按内容选定最合适的题型，合计单选 4658、多选 610、填空 825、简答 1907、代码 21；题型最多这五种，一章只用到其中一两种也正常。选择题的题干和选项只存在于 `content/typed/`，本目录的题卷里仍是原来的简答问法。所有章节继续保持 `draft`，等待人工抽查。
