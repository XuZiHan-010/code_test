# Claude Code 行业观察专题面试题

来源：[图解 Claude Code](https://xiaolinnote.com/claudecode/)的行业观察专题，共 3 篇文章。每篇一个题组，每个编号只考一个主要问题；本卷使用 `J` 前缀。

本卷将研究解读、产品观察和水印机制拆成理解与判断题。原文里的调查比例、模型版本、发布日期、部署状态和法规说法均需另行核实；不要求将这些数字或说法作为事实背诵。

## 3. 文字水印的原理与检测边界
