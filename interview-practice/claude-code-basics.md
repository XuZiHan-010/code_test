# Claude Code 基础入门专题面试题

来源：[图解 Claude Code](https://xiaolinnote.com/claudecode/)的基础入门专题，共 3 篇文章。沿用原题卷的拆题方式：每篇一个题组，每个编号只考一个主要问题；本卷使用 `F` 前缀。

题目依据文章正文整理，命令、模式名称、权限范围和模型设置可能随版本变化。回答具体操作时应说明版本，并核对实际设置；文章中的使用经验不视为所有环境都成立的保证。
