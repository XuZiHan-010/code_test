# Codex 专题面试题

来源：[图解 Codex](https://xiaolinnote.com/codex/)，共 4 篇文章（基础入门 1 篇、实践技巧 1 篇、源码解析 2 篇）。每篇一个题组，每个编号只考一个主要问题；本卷使用 `N` 前缀。

题目只考原文讲到的内容。与 Claude Code 题卷相近的机制（项目规则、Skill、子代理、上下文压缩、长期记忆）保留 Codex 自己的实现视角，不做跨卷去重。文章中的模型名称、默认值、阈值和源码细节按原文背景理解，不作为已经核实的产品规格。
