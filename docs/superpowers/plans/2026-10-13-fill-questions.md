# 填空题调整与实施

用户已要求在现有题库中增加填空题，并由 DeepSeek 按语义评判。本次沿用既有界面、题号、题序和原文答案，不提交已有的其他修改。

1. 通读各专题的列举、组成、分类和步骤题，对照现有参考答案选取适合填空的题。解释、比较和情景推理保留简答，不机械按疑问词转换。
2. 题干标注 `[填空题·无序]` 或 `[填空题·有序]`，用 `____` 表示每个空；typed 数据使用 `fill`、`blankCount` 和 `blankOrder`。Harness 六层改为六空，保留分组语境。
3. 补充内容校验、合并和目录视图。作答视图只包含空数及顺序要求，不包含参考答案。
4. 增加 `{ blanks: string[] }` 作答格式，接入输入、保存、恢复、交卷和结果展示。复用 JSONB 存储和现有异步评分，不做数据库迁移。部分填写仍可保存并送评，全空按未答处理。
5. DeepSeek 对填空按全部空覆盖判对，接受语义等价、中英文术语；无序列举不要求原文顺序，重复答案不抵缺漏，有序题按对应位置判断。保持整题对错计分。
6. 补充行为测试：内容校验和答案隔离、保存格式与长度、部分填答、全空、后台评分、错误统计与结果。运行内容校验、单元和集成测试、类型检查与 lint。

所有未人工抽查的章节继续保持 draft。其他专题的 typed 数据只把已有题目标为简答或填空，不生成未经审核的选择题。
