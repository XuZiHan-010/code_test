## 可选澄清与未列为问题的事项

- `stash pop` 的删除应限定成功应用后；冲突时 stash 保留。建议联动 X2-45、46、50、52。它们按正常成功流程提问，本轮不认定为选项字母错标。[官方说明](https://git-scm.com/docs/git-stash)。
- `--force-with-lease` 更精确的说法是比较远程引用当前值与本地预期值，而非检测“别人是否曾推送过”。X2-27、30 可收紧解析。[官方说明](https://git-scm.com/docs/git-push)。
- X1-21 的 D“继续作为快照暂存在 index”可能被理解为提交后索引仍保留版本引用；建议改成“不会生成 commit，只停留在暂存阶段”。
- X3-32、41 的快进条件宜直接写成“当前 main 的 tip 是 feat/a tip 的祖先”，减少分支分出方向的文字混淆。
- X2-19 的口诀填空考的是原文比喻，教学价值可以优化，但空数、顺序及参考答案本身对应，不报填空错误。
